# V7 economic proof protocol

The canonical economic headline is `REALIZED_AND_SETTLED_NET_PNL` in integer
pUSD base units. It is valid only when a hash-chained production journal and a
separate read-only verifier agree exactly, with no unresolved order, fill, cash,
position, settlement, or source-evidence break.

PAPER, counterfactuals, marks, quoted edge, telemetry and incentives cannot
satisfy this claim. The verifier must bind the exact code SHA, run manifest,
wallet/session identity hashes, raw-source manifests, and attestation.

Economic promotion requires pre-registered terminal independent units, positive
2x-cost cluster lower confidence bound, reward-free sensitivity, capacity tiers,
tail-risk limits and multiple forward regimes. It never performs promotion.

Portfolio-level economic proof also requires at least 90 elapsed forward days
between the first and last immutable terminal sample; dense intraday samples do
not substitute for calendar time or multiple regimes.

The scorecard rejects a portfolio whose 95% expected shortfall is worse than
5% of the sample capital unit, even when its aggregate PnL is positive.
